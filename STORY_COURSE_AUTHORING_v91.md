# Story Course authoring — v91

## Repository structure

A complete work lives under one story folder:

```
decks/de/stories/<story-folder>/
  story.json
  source-map.csv
  ch01/
    unit.json
    sentences.csv
    words.csv
    anchors.csv
    patterns.csv
  ch02/
    ...
```

`story.json` is a content manifest only. Do not store learner progress in it.

## Story hierarchy

- **Story:** the complete work or coherent course arc.
- **Chapter:** a loading and validation unit. Keep the source author’s chapters whenever possible.
- **Section:** a natural scene or stopping point, authored in the existing `scene` column.
- **Block:** generated by the Story Study engine in 3–6 sentence cycles. Do not author block numbers.

A section boundary belongs where a reader could naturally pause. Do not split only to satisfy arithmetic.

## Canonical lexeme IDs

Every `words.csv` row requires `lexeme_id`.

Use:

```
<language>.lex.<lemma-or-stable-slug>[.<sense>]
```

Examples:

```
de.lex.lesen
de.lex.bank.financial
de.lex.bank.bench
```

The ID must remain stable if `pos`, translation or spelling metadata is corrected. Use `pos` and `sense` columns in the global lexicon for linguistic truth. Reuse existing canonical IDs before creating new ones.

## Chapter unit requirements

Each `unit.json` remains Story Study schema v2 and includes:

- `storyId`
- `chapterId`
- `chapterTitle`
- `chapterOrder`
- `chapterCount`
- standard sentence, word, anchor and pattern file names

The chapter must load independently.

## Sentence requirements

Every sentence must have:

- stable `id`;
- continuous `seq`;
- authored `scene`;
- English and target text;
- authored `chunks`;
- pattern IDs when applicable.

Do not derive chunks mechanically from punctuation.

## Word requirements

Every content token must resolve through:

1. `words.csv`, or
2. the shared language `lexicon.csv`.

Discontinuous and separable forms require explicit anchors. The same lexical meaning must use the same canonical ID across all chapters and Words decks.

## New vocabulary budget

The default v91 preparation batch is ten lexemes. A natural scene may contain more than ten first-seen lexemes, but the Course must divide preparation into multiple batches. The Builder reports this numerically.

For an ambitious learner, prefer meaningful language and natural scenes over excessive simplification, but do not silently place 20–30 unseen items into a single preparation step.

## Full-source coverage

For a copyrighted-safe or authorised source, process the complete work from beginning to end. Do not stop after an arbitrary 35–50 sentence sample and do not reduce the work to a synopsis.

`source-map.csv` records how each source span maps to target chapters and scenes. Important events, clues and resolution must all be represented.

## GitHub installation

Upload the generated folder under:

```
decks/<language>/stories/<story-folder>/
```

The v91 Course screen scans GitHub Pages for story folders and lists valid `story.json` packages automatically. No Text manifest entry is required for Course use.

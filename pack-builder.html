Build a v87 language pack

This tool creates the package structure and a staged AI master prompt. It does not fabricate thousands of learning items in the browser: the generated prompt directs an AI to produce them in validated batches, then this page checks the completed folder before it is added to decks/.

1. Package plan

2. Master prompt

The prompt requires staged output, reuse of the central lexicon, stable sense-aware IDs, exact surface forms, real scene boundaries and a validation pass. Frequency ranking must come from a supplied or cited frequency list, not from AI memory.

3. Story Study text unit

Create a manifest-driven Story Study unit that can be imported directly into the app. The completed unit must resolve every word-like token in Complete coverage; highlighted “key vocabulary” alone is not sufficient.

4. Merge generated CSV batches

Choose batch files with the same header. The merger preserves the first row for each stable key, reports conflicting duplicates, and downloads one RFC-4180 CSV.

5. Validate and package a completed folder

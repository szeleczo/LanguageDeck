# LanguageDeck 3.1.8 — Keyboard Ergonomics

- Preserves the standard German QWERTZ layout and the existing keyboard design.
- Enlarges all QWERTZ touch targets to at least 46 px high.
- Reduces horizontal key gaps to 1.5 px and keyboard side padding to 3 px, giving the 11-key top row more usable width.
- Adds release-time slide correction: while holding a key, the learner may slide to a neighbour; only the key under the finger at release is entered.
- Applies the same touch behaviour to the main recall keyboard, Text Study keyboard and Story Study letter bank.
- Preserves mouse click and physical-keyboard accessibility and prevents duplicate characters after pointer input.
